# 数据产品说明

## 1. 中小企业经营增信线索包

面向园区、银行、担保机构和企业服务部门。输入公开工商、招投标、资质、股权和融资数据，输出 OCS 分解、融资可见性、候选企业名单和核验建议。

关键交付：

- 企业级 OCS 与五维分解
- 有中标痕迹但无公开融资记录的企业清单
- 证据 ID、数据时间、局限和人工核验字段

使用边界：只做线索发现，不自动授信，不替代财务、纳税、订单和征信审核。

## 2. 资质续期提醒服务

面向企业服务中心、园区和企业自身。把年度制度性到期与多年期资质失效分开，按天数生成提醒清单。

关键交付：

- 未来 12 个月到期列表
- 曾有效但当前全部失效的企业
- 按资质类型的有效率和数据覆盖

使用边界：提醒不是处罚依据，续期状态以主管部门和企业原件为准。

## 3. 产业协作与区域体检简报

面向产业招商、园区运营和产业政策部门。用公告共现关系和区域聚合结果辅助识别产业枢纽、区域差异和需要补充数据的行业。

关键交付：

- 产业网络节点、边、关系语义和连通性
- 区县健康指数与构成
- 行业空转预警和成立/招投标趋势

使用边界：共现关系不是合同关系，空转预警不是对行业或企业的定性结论。
