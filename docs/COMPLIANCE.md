# 合规与安全边界

## 数据边界

- 原始 Excel、Parquet、DuckDB 和报告产物默认不提交 Git。
- 分析层只访问五个派生视图，原始表不直接暴露给 Agent。
- 企业名单只用于线索发现和人工核验，不做自动授信、处罚、黑名单或政策认定。
- 没有纳税、专利、诉讼、征信和财务报表字段时，报告必须明确写“当前数据不可见”。

## 输出边界

- 不在 SQL、日志、报告、HTML、PDF 或截图中写入模型 Key、数据库密码、访问口令。
- 不把“零融资记录”改写成“从未融资”。
- 不把公告共现改写成已确权合作。
- 不把行业空转预警改写成行业造假或低效结论。
- 空结果必须说明“没有匹配记录”，禁止编造趋势、排名或原因。

## 交付前检查

```powershell
python scripts\check_security.py
python -m pytest -q
```

所有报告在 `CriticAgent` 通过证据质量门后才生成。数据口径变化必须同时修改 `docs/METHODOLOGY.md` 和对应测试。
